# Review
Read locked task, rules, diff, source, and test/CI evidence yourself. Check scope, correctness, edge cases, auth/privacy, framework compatibility, performance/DB where relevant, and meaningful test gaps. Return APPROVE, REJECT, or NEEDS_HUMAN with evidence; do not manufacture style-only blockers.
