# Project plan
Read root/local AGENTS, current source/tests, and relevant stable docs only. Record scope, acceptance, seams, risks, tests, and blocking decisions. For multi-session work use only `state.md`, `progress.md`, and `implementation-plan.md` unless a phase truly needs its own detail. Do not invent architecture/product/security/schema decisions or treat planning as authorization to write remotely.
